# Python Exercises

Learning project: a collection of Python exercises organized into numbered folders. Each folder contains a short script tackling a specific problem, such as sequence generation and string manipulation.

## Tech stack

- Python 3

## Exercise index

| Folder | File | Description |
|--------|------|-------------|
| `2/` | `Fibbonaci.py` | Generates the Fibonacci sequence up to a given number and checks whether the input belongs to it |
| `3/` | `inverter.py` | String/sequence reversal exercise |
| `4/` | `inverter.py` | Variation of the reversal exercise |

## Getting started

Run any script directly with Python:

```bash
python 2/Fibbonaci.py
python 3/inverter.py
```

Python 3 is required. No external dependencies.
